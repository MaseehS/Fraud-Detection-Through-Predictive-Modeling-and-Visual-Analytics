# Fraud-Detection-Through-Predictive-Modeling-and-Visual-Analytics
Project Overview

In today’s digital economy, businesses face increasing threats from fraudulent transactions, especially in finance, e-commerce, and online services. Detecting fraud in real-time is critical to minimizing losses and maintaining customer trust. This project simulates a real-world fraud detection workflow by analyzing transaction data using machine learning and visualizing the insights with Tableau to support data-driven decision-making. volumes.

Project Goal

The objective of this project is to develop a machine learning model that accurately classifies fraudulent transactions using a synthetic dataset of 50,000 records. The dataset includes features such as Risk Score, Transaction Amount, and Failed Transaction Count (7 days), which are used to train and evaluate binary classification models to improve fraud detection efficiency.

Business Impact

Support real-time fraud detection to:
1. Reduce financial loss
2. Improve operational efficiency
3. Minimize false positives to avoid overwhelming investigation teams

Tools Used
1. Python: Data cleaning, modeling, evaluation
2. Tableau: Visual storytelling and stakeholder reporting
